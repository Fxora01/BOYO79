## What Interests Me

- **API design** with clear inputs, predictable responses, and useful errors.
- **Application logic** that expresses business rules without unnecessary complexity.
- **Data handling** that keeps related information consistent.
- **Service integrations** that account for timeouts, retries, and unexpected responses.
- **Backend testing** that checks meaningful behavior and failure cases.

| Area | Questions I Want to Explore |

## Development Priorities

- Start with a small feature and explicit expected behavior.
- Keep validation, application rules, and storage responsibilities understandable.
- Consider invalid requests and interrupted operations alongside successful paths.
- Use tests to explain behavior and catch regressions.
- Document setup, API examples, and important design assumptions.
